# RPG Character Manager

A simple Java console application where you can create and manage RPG characters.

## Features

- Display all characters and their stats
- Create new Warriors, Mages, and Archers
- Choose a character to attack
- Use each character's special attack
- Search for a character by name
- Display character stats

## What I practiced

I built this project to practice object-oriented programming in Java. It helped me understand inheritance, abstract classes, interfaces, and method overriding.

Each character type has its own attributes and attack methods.

## Technologies

- Java
- IntelliJ IDEA

## How to run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure Java is installed.
4. Run `Main.java`.
